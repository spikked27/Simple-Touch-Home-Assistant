# Simple Touch 1.1.1

- Favorite, partial, and unknown positions now display as **Open** in Home Assistant. The `assumed_position` attribute preserves the specific status; no percentage is invented. Offline bridges remain **Unavailable**.
- Documented Favorite support in Scheduler Card using its custom actions.

Update the integration through HACS and restart Home Assistant. This fix works with firmware 1.1.0; a firmware update is not required. Firmware 1.1.1 only updates the version label.
