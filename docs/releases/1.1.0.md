# Simple Touch 1.1.0

- New **Simple Touch: Go to favorite position** Home Assistant action targets shade covers directly in automations and scripts. Existing Favorite buttons remain available. No percentage slider is enabled.
- **Visit device** opens the bridge automatically from its local network, without copying a key. Local access is limited to direct clients on the bridge subnet using its IP address or hostname; control APIs still require the bridge key.
- Home Assistant 2025.10 or newer is required for the entity action API.

Update firmware from bridge Settings or its Home Assistant firmware update entity. Update the integration through HACS, then restart Home Assistant. Pairings and settings are preserved.
