# Simple Touch 1.0

The first stable release for the tested Simple Touch shade family, using a Seeed XIAO ESP32-S3 and a 433 MHz CC1101 radio.

## Start here

1. Follow the [wiring and setup guide](https://github.com/spikked27/Simple-Touch-Home-Assistant/blob/main/docs/getting-started.md).
2. Open the [browser installer](https://spikked27.github.io/Simple-Touch-Home-Assistant/) in desktop Chrome or Edge.
3. Connect Wi-Fi, visit the bridge, and add a shade using guided pairing.
4. [Add Simple Touch to HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=spikked27&repository=Simple-Touch-Home-Assistant&category=integration), install, and select the discovered bridge in Home Assistant.

## Included

- Open, Close, Stop and Favorite, with up to 32 virtual remotes per bridge.
- A responsive local web interface, guided pairing, and physical-remote linking.
- Home Assistant cover and Favorite button entities, automatic bridge discovery, and firmware update support.
- Persistent remote identities, reserved counters, backups and data-preserving updates.
- Independent radio reception and one-second state refreshes, so quick physical Open/Stop sequences no longer wait for a five-second display refresh.
- Light/dark brand icons and a concise installation guide.

## Existing installations

Update **both** parts: firmware through the bridge webpage (or Home Assistant's firmware update entity), and the integration through HACS. Restart Home Assistant after updating the integration. Refresh any open bridge tabs. Do not erase user data or repeat pairing.

For manual OTA, use `simple-touch-esp32s3-update.bin`. The `simple-touch-esp32s3-install.bin` merged image is for USB installation, not the bridge's manual OTA upload. `updates.json` records the application image's SHA-256 and size.

## Position and compatibility

The motor provides no position feedback. A configurable travel window defaults to 60 seconds. Stop during that window assumes partial; Stop after it preserves the endpoint. Home Assistant reports partial as Open with `assumed_position: partial`. No percentage is fabricated.

Compatibility is limited to the tested Simple Touch protocol and XIAO ESP32-S3 build. The radio cannot hear physical remotes while transmitting. RF range and interference vary by installation. Some HACS versions have an upstream issue displaying bundled custom-integration icons; the assets are included here.

See [testing status](https://github.com/spikked27/Simple-Touch-Home-Assistant/blob/main/docs/testing.md) for hardware observations, automated checks and remaining compatibility work.
