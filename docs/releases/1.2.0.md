# Simple Touch 1.2.0

- **Restart bridge** in webpage Settings and a native **Restart** button on the Home Assistant bridge device. Both verify a new boot before reporting success; saved settings are retained.
- Home Assistant diagnostics: Wi-Fi signal, IP address, uptime (minutes), reset reason, update status, and radio problem. Optional FIFO-overflow and receive-queue-drop sensors are disabled by default.
- Verified uploads schedule restart before the HTTP completion handler, using an independent timer. A lost final response no longer leaves restart dependent on HTTP handling.
- Update confirmation checks both boot identity and target version. Home Assistant pauses its inventory polling during maintenance. Failed uploads report their received byte count and error without an automatic retry.

Update both the integration through HACS (then restart Home Assistant) and the bridge firmware. Diagnostics unsupported by older firmware remain unavailable until its update. Restart retains shades, links, counters, and Wi-Fi settings; shade position remains assumed after boot.
